# litrik-site

Публичные страницы «Литрика» для магазинов приложений: поддержка и политика конфиденциальности. Временный хостинг на GitHub Pages до своего домена (решение G45).

- `privacy.html`, `privacy.css` — копия `Litrik/shared/generated/` (источник — `Litrik/docs/legal/privacy-policy.md`, генератор `gen-privacy.mjs`). Руками не править: обновлять копированием.
- `support.html`, `index.html` — страницы поддержки и описания.

Кода приложения здесь нет.
